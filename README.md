## 🌱 Now building: [Mawta](https://github.com/amaru-one/mawta)

An open-source gradebook for Peruvian schools, where AI drafts and the teacher decides.

Teachers in Peru assess every student by competency: they plan, collect evidence, assign a
level each term and write a conclusion for each one. Mawta puts agents next to them for the
drafting:

- **Planning agent** — turns a teacher's idea into a learning experience built on the
  national curriculum: criteria, planned evidence and sessions.
- **Conclusions agent** — drafts a student's descriptive conclusion, citing the evidence and
  voice notes behind every point.
- **Name sweep** — removes the names a teacher says out loud before any other agent reads
  the note.
- **Director chat** — a LangGraph agent that answers the school leadership's questions in
  Spanish through read-only SQL tools.

Nothing is saved until the teacher accepts it, and no agent ever sets a grade. Every agent
runs on open models, from Ollama on a laptop to a GPU server at the school.

## 🧭 How I build AI

<table>
  <tr>
    <td width="50%"><b>The model drafts, a person decides.</b><br>Agents propose; the people accountable for the result accept, edit or discard.</td>
    <td width="50%"><b>Answers come from data.</b><br>Agents use tools and cite their sources; tables come from the database, not from the model's memory.</td>
  </tr>
